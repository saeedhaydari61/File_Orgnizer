File Organizer

A simple desktop application written in Python that automatically organizes files into folders based on their file extensions.

Features
Browse and select a folder using a graphical interface
Automatically sort files by extension
Create destination folders automatically
Prevent overwriting files with duplicate names
Display sorting status in the application
Simple and user-friendly Tkinter interface
Standalone Windows executable (.exe)
Technologies
Python 3
Tkinter
pathlib
shutil

How to Run
Option 1

Run the Python script:

python main.py
Option 2

Run the executable:

dist/FileOrganizer.exe

No Python installation is required.
